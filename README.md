# hello-git

我的第一个 GitHub 项目 🎉

## 这是什么

这是一个用 DeepSeek Harness 帮忙创建的示例项目，用来演示：

1. 初始化一个本地 Git 仓库
2. 创建一些文件并提交
3. 推送到 GitHub

## 文件说明

| 文件 | 说明 |
|------|------|
| `README.md` | 项目介绍（就是你正在看的这个） |
| `hello.py` | 一个简单的 Python 问候程序 |
| `.gitignore` | 告诉 Git 忽略哪些文件 |

## 如何运行

```bash
python hello.py
```

## Git 常用命令速查

```bash
git init          # 初始化仓库
git add .         # 暂存所有更改
git commit -m "msg"  # 提交
git push          # 推送到远程
git pull          # 拉取远程更新
```
